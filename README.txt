【游戏流程（两个版本一样）】

  阶段一：加入 → 主持人添加所有参与者
  阶段二：填卡 → 每人写三条信息（代际/冷知识/标志事件）
  阶段三：竞猜 → 随机分配卡片，轮流猜主人
  阶段四：猜真假 → 选一条真信息+编两条假的，全场投票
  阶段五：合影 → 所有卡片拼成马赛克，撒花！

【文件说明】

  standalone.html  ← 单机版（双击即用）
  START_HERE.bat   ← 启动菜单（双击选版本）
  server.js        ← 多设备版服务器
  public/
    host.html      ← 主持人专用页面
    index.html     ← 玩家页面
